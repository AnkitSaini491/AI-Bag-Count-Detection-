# AI-Bag-Count-Detection-
AI-Based Bag Count Detection using Python, OpenCV, YOLO, and ByteTrack.
AI Bag Count Detection System

An AI-based project that detects and counts bags in video footage using Python, OpenCV, YOLO, and ByteTrack.

Features

- Bag detection using YOLO
- Object tracking using ByteTrack
- Automatic counting when objects cross a virtual line
- Bounding boxes and object IDs
- Live count display

Technologies Used

- Python
- OpenCV
- YOLO
- ByteTrack

Installation

Install the required libraries:

pip install -r requirements.txt

How to Run

1. Place your trained YOLO model in the project folder as "best.pt".
2. Place your input video in the same folder as "input.mp4".
3. Run the Python file:

python main.py

Applications

- Warehouse inventory management
- Industrial bag counting
- Packaging and material handling

Note

A trained YOLO model suitable for bag detection is required for accurate results.
